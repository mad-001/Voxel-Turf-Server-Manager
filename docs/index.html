Voxel Turf Server Manager

Connect your Voxel Turf server to Takaro — Discord chat bridge, server announcements, and admin control from the Takaro dashboard.

Download Latest Release Sign Up for Takaro (Free)
Chat Bridge Player chat forwarded to Takaro in real time. Reply from the dashboard or Discord.
Player Events Join, leave, and death events automatically tracked in Takaro.
Admin Actions Kick, ban, broadcast messages, and give items directly from Takaro.
Server-Side Only No client mod required. Loaded as a plain Voxel Turf server mod.

How It Works

Voxel Turf Server                    Bridge (Node.js)           Takaro
┌──────────────────────────┐         ┌────────────────────┐    ┌──────────────┐
│ TakaroConnector Lua mod  │         │ VoxelTurf-Bridge   │    │ Takaro Cloud │
│  · player events         │──HTTP──▶│  · WebSocket client│──▶│ wss://connect│
│  · chat capture          │◀──HTTP──│  · command queue   │◀──│  .takaro.io/ │
│  · kick / ban / give     │         │  · player cache    │    │              │
└──────────────────────────┘         └────────────────────┘    └──────────────┘

The Lua mod runs inside your Voxel Turf server and communicates with a small Node.js bridge process running on the same machine. The bridge maintains the persistent WebSocket connection to Takaro and translates between the two protocols.

Step 1 — Get a Takaro Account

  1. Go to takaro.io/pricing and pick a plan.
  2. Sign up and confirm your email, then log in at app.takaro.io.

Step 2 — Register Your Server in Takaro

  1. In the Takaro dashboard, click Game Servers → Create Game Server.
  2. Choose Generic as the server type.
  3. Give the server any name you like.
  4. Takaro will generate a Registration Token. Copy it — you'll paste it into the config in Step 4.

Step 3 — Install the Mod

Download the latest release ZIP and extract it. Inside you'll find a folder named TakaroConnector. Copy that entire folder into your Voxel Turf server's mods\ directory:

C:\path\to\voxelturf\server\
├── mods\
│   └── TakaroConnector\           <-- copy here
│       ├── scripts\
│       │   ├── server_scripts.txt
│       │   └── server\
│       │       └── takaro_connector.lua
│       └── TakaroConfig.txt
└── VoxelTurf.exe                  (already there)

Step 4 — Configure the Mod

Open mods\TakaroConnector\TakaroConfig.txt and fill in two fields:

BRIDGE_URL=http://127.0.0.1:3003
POLL_INTERVAL=2
ENABLED=true

Leave BRIDGE_URL as-is if the bridge runs on the same machine as the game server (the default). The mod reads this file on every server start.

Step 5 — Configure and Start the Bridge

From the release ZIP, copy the VoxelTurf-Bridge folder anywhere on your server (or the same machine). Open TakaroConfig.txt inside it:

SERVER_NAME=My Voxel Turf Server
REGISTRATION_TOKEN=paste-your-token-from-step-2-here
HTTP_PORT=3003
KeyRequired?Description
SERVER_NAMEYesAny name — used as the identity with Takaro.
REGISTRATION_TOKENYesToken copied from the Takaro dashboard in Step 2.
HTTP_PORTOptionalLocal port the bridge listens on. Must match BRIDGE_URL in the mod config. Default 3003.
Node.js required. The bridge needs Node.js 18 or newer. Download it free at nodejs.org. After installing Node, double-click start.bat inside the VoxelTurf-Bridge folder — it installs dependencies and starts the bridge automatically.

To start the bridge: double-click start.bat. Keep the window open while the server runs. To stop it: close the window or double-click stop.bat.

Step 6 — Start Your Voxel Turf Server

Start your Voxel Turf server normally. The mod loads automatically because it's in the mods\ folder — no launch-flag changes needed. You should see this line in the server console shortly after startup:

[TakaroConnector] Started. Bridge: http://127.0.0.1:3003

Step 7 — Verify It's Working

  1. In the bridge window, look for: Identified with Takaro and HTTP server listening on http://127.0.0.1:3003.
  2. Refresh your server's page in the Takaro dashboard — the Reachable indicator should turn green within a few seconds.
  3. Have a player join. A player-connected event should appear in Takaro's event stream.
  4. Type in chat — it should appear in Takaro as a chat-message event.
Admin status command. Once in-game, any admin can type /takarostatus in chat to get a status report from the mod (bridge URL, number of tracked players, tick count).

Troubleshooting

Mod line doesn't appear in the server console

Confirm the mod folder structure is exactly as shown in Step 3. In particular, check that server_scripts.txt exists inside TakaroConnector\scripts\ — this is the file the engine scans to find mod scripts.

Bridge connects but Takaro says "Unreachable"

  • Confirm REGISTRATION_TOKEN in the bridge config matches the token shown in the Takaro dashboard.
  • Outbound HTTPS to connect.takaro.io:443 must not be blocked by your firewall or hosting provider.
  • If the registration token was already consumed, regenerate it in the Takaro dashboard.

Bridge starts but the mod can't reach it

  • Confirm HTTP_PORT in the bridge config matches the port in BRIDGE_URL in the mod config.
  • If the bridge is on a different machine, replace 127.0.0.1 in BRIDGE_URL with the bridge machine's LAN IP.
  • Windows Firewall may block inbound connections on port 3003 — add an inbound rule to allow it.

Server console shows [TakaroConnector] INIT ERROR

This means the Lua mod crashed during initialization — usually a missing API. Check the error text after the colon and open a GitHub issue with the full line.

Anything else

Open an issue at github.com/mad-001/Voxel-Turf-Server-Manager/issues and include the bridge log (voxelturf-bridge.log in the bridge folder) and your server console output.
